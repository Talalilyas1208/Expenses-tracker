# 💰 Expenses Tracker

A modern, full-featured personal finance management application built with **React 19** and **Ant Design**. Track expenses, manage income, monitor wallets, and analyze spending patterns with an intuitive dashboard interface.

---

## 🎯 Overview

**Expenses Tracker** is a web-based financial management tool designed to help users:
- **Track Expenses**: Log expenses with categories, descriptions, and timestamps
- **Manage Income**: Record income entries and monitor cash flow
- **Monitor Wallets**: View wallet transactions and current balance
- **Plan Budgets**: Track days until salary with a built-in countdown feature
- **Categorize Spending**: Organize expenses and income by customizable categories
- **View History**: Review transaction history and previous transactions
- **Transfer Funds**: Move money between wallets seamlessly

---

## 📦 Tech Stack

- **Frontend Framework**: React 19.1.1
- **UI Library**: Ant Design (antd) 5.27.1
- **Routing**: React Router DOM 7.8.2
- **Build Tool**: Create React App (react-scripts 5.0.1)
- **Testing**: @testing-library (React, Jest-DOM, User Event)
- **State Management**: React Context API
- **Storage**: Browser LocalStorage (for persistent data)
